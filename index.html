🌐 Passage 50 Hz $\leftrightarrow$ 60 Hz

Comportement magnétique et vitesse

Lorsqu'un moteur 50 Hz est utilisé sur un réseau 60 Hz (ou inversement) :

  • Vitesse de rotation : Augmente de 20% en 60 Hz ($N_{60} = 1.2 \times N_{50}$).
  • Rapport $V/f$ constant : Pour garder le même flux magnétique, la tension doit augmenter proportionnellement ($400\text{V} @ 50\text{Hz} \to 480\text{V} @ 60\text{Hz}$).
  • Rebobinage spécifique : Si la tension reste identique ($400\text{V}$), le nombre de spires doit être réduit de $17\%$ : $N_{60} = N_{50} \times (50/60) = 0.833 \times N_{50}$.
